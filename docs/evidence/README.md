# Evidence — gdrive-mounts

Dated receipts for claims that need proof, not prose: bakeoffs, acceptance
runs, promotion roundtrips. Not a place for plans or drafts — see
`docs/tracker.md`, and the operating repo's `docs/agent-notes/` for the
work-plan, for those.

## Naming

`YYYY-MM-DD-<topic>.md`, one file per receipt. Don't append to an old dated
file for a new event — write a new one and let the tracker link both.

## What a receipt must include

- The commands actually run, verbatim.
- Their actual output (or the load-bearing excerpt, with the cut marked).
- A verdict line: what this receipt proves, in one sentence.

A claim with no command-and-output pasted next to it is a plan, not
evidence — move it back to the tracker or the work-plan.
